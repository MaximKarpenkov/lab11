## HTTP-упражнение
- Адрес `https://api.github.com/users/<login>` — ресурс API профиля GitHub (не репозитория).
- Метод **GET** — чтение ресурса.
- `timeout=10` ограничивает время ожидания ответа; при превышении — `TimeoutError`/`socket.timeout`.
- Обработчики:
  - `HTTPError` — сервер вернул HTTP-код (404 — не найден, 403/429 — ограничения).
  - `URLError`, `TimeoutError`, `socket.timeout` — сетевые проблемы.
  - `ValueError`, `UnicodeError` — некорректные данные/кодировка.
  - `OSError` — файловые ошибки.
- Меню: 1 — сеть, 2 — локальный `profile_sample.json` (учебные данные `{"login": "demo", "id": 1, "name": null}`).
  Отсутствие интернета не снижает оценку — локальный режим равноценен.
